# QQ 桥接插件（qq-bridge）

把桌宠「大肥鱼」接到 QQ。基于 **OneBot v11** 协议，推荐搭配 [NapCat](https://github.com/NapNeko/NapCatQQ)。

```
QQ ──> NapCat ──(HTTP 上报)──> 本插件 127.0.0.1:6199/onebot
                                  │
                                  ├── 取本体「API 配置」里的 DeepSeek Key
                                  ├── 人设 + 语气 + 模板 + 每会话记忆
                                  └──(HTTP API)──> NapCat /send_msg ──> QQ
```

## 一、五分钟接入（向导）

1. 右键桌宠 → **QQ 接入向导**（或设置 → QQ 桥接 →「🧭 打开接入向导」）。
2. **第 1 步 环境检查**：确认插件在监听；点「测试 NapCat 连接」。
3. **第 2 步 配置 NapCat**：按页面提示在 NapCat WebUI 建两条配置——
   - HTTP 服务器：端口 `3000`；
   - HTTP 上报：地址用页面上复制到的那条（`http://127.0.0.1:6199/onebot`），格式选 **array**。
4. **第 3 步 身份与安全**：填机器人 QQ、主人 QQ、Token、唤醒方式、白名单。
5. **第 4 步 人设与语气**：选模板、调语气，右侧实时预览最终提示词。
6. **第 5 步 自检**：测试 NapCat、测试 DeepSeek，再「模拟一句话」看她的回复（不会发到 QQ）。

每步点「保存并下一步」都会立即落盘，设置页和向导改的是同一份配置。

## 二、人设与语气

| 项 | 说明 |
| --- | --- |
| 人设模板 | 默认·大肥鱼（精简）/ 大肥鱼（社区完整人设）/ 傲娇 / 温柔 / 简洁 / 自定义 |
| 自定义人设 | 只有选「自定义」时生效，可以整段粘贴别人的人设 |
| 语气 | 默认 / 更活泼 / 更冷淡 / 更黏人 / 更毒舌（叠加在人设上） |
| 口头禅 | 例如「饿了」，提示模型偶尔自然带一句，不会每句都用 |
| 每次最多几条 | 1–5 条 |
| 每条最多几字 | 10–300 字 |
| 颜文字 / emoji | 不用 / 偶尔 / 常用 |
| 兜底回复 | 模型超时、报错或空回复时发这一句；留空则不回 |

最终提示词 = 人设 + 语气 + 口头禅 + 输出格式 + 底线，`{OWNER_QQ}` 会替换成「主人 QQ 号」。
第 4 步的「提示词预览」就是模型实际收到的那段文字，改任何选项都会实时刷新。

## 三、完整设置项

| 字段 | 说明 |
| --- | --- |
| 启用桥接 | 关闭后完全不监听、不回复 |
| 本机监听端口 | 默认 6199，对应 NapCat 的 HTTP 上报地址 |
| NapCat HTTP 地址 | 默认 `http://127.0.0.1:3000`，用于回发消息 |
| OneBot Token | 与 NapCat 里填的一致；没填就留空 |
| API Key / API 地址 | 留空 = 使用本体「API 配置」里的值 |
| 机器人 QQ 号 | 可留空，按上报的 `self_id` 自动识别 |
| 主人 QQ 号 | 人设里 `{OWNER_QQ}` 的替换值 |
| 群聊唤醒方式 | @她 或 叫名字 / 只在被 @ 时 / 群里每条都回 |
| 唤醒关键词 | 默认 `大肥鱼,肥鱼,小鱼,鲸鱼` |
| 群白名单、私聊白名单 | 每行一个号；留空表示不限制 |
| 模型 | `deepseek-flash` 或 `deepseek-v4-pro` |
| 随机性 / 单次上限 / 记忆轮数 | 生成参数与每会话保留的问答轮数 |

## 四、行为说明

- 私聊：白名单为空时所有人可聊；有白名单时只回名单内的人。
- 群聊：默认只有 **@她** 或 **消息里出现关键词** 才回复；`all_in_group` 会回每条（不建议大群）。
- 回复按行拆成「每次最多几条」以内的短消息发出，每条超过「每条最多几字」会被切开。
- 每会话 1.2 秒内只处理一条，避免刷屏和自触发。
- 模型报错/超时/空回复 → 发「兜底回复」，并在状态窗口记一条错误。
- 会过滤模型偶尔吐出的 `<system_reminder>`、`DSML` 等内部标签。
- 记忆与统计保存在 `%APPDATA%\DeskLLMPet\plugins\qq-bridge\state.json`。

## 五、排错

| 现象 | 处理 |
| --- | --- |
| 状态窗口「监听失败」 | 端口被占用，换端口并同步改 NapCat 上报地址 |
| 收到了事件但不回复 | 检查唤醒方式、白名单、Token 是否一致 |
| 回复 401 | 本插件 Token 与 NapCat 上报 Token 不一致 |
| 回复「发送失败」 | NapCat 的 HTTP 服务器没开，或地址/端口不对 |
| DeepSeek 报 402 | 开放平台余额不足 |
| DeepSeek 报 404 | 模型名写成 `deepseek-flash` / `deepseek-v4-pro` |
| 回复太啰嗦 | 调小「每次最多几条」「每条最多几字」，语气选「更冷淡」 |

## 六、卸载

把 `plugin.json` 里的 `"enabled"` 改成 `false`，或从 `app.asar` 删除 `src/plugins/qq-bridge` 后重新打包。

## 七、想要更完整的人格

社区有更完整的「大肥鱼」人设（表情包、语音、主动聊天、长期记忆），例如
`zexuanw958-svg/dafeiyu-config-pack`。本插件只负责把桌宠接到 QQ；想要那些人设，
可以把那边 `persona/大肥鱼.md` 整段粘贴到「自定义人设」，或直接选内置的「社区完整人设」。
