DeskLLMPet · 接入 QQ（手机也能聊）
====================================

一句话：用一个 QQ 小号在电脑上挂着大肥鱼，你从手机大号私聊它就行。
手机 QQ 什么都不用装、也不用连同一个 Wi-Fi。

准备
----

首次启动会自动打开「QQ 接入向导」：先填角色名、身份、性格、回答方式，
第 5 步还能勾选：共享大脑、原话检索、省钱裁剪、预算阀、防复读、防空转、联网查询。

一个小号 QQ（专门给大肥鱼用）。不建议用主号，第三方登录有被限制的风险。

第 1 步  装 NapCat
------------------
1. 打开 https://github.com/NapNeko/NapCatQQ/releases/latest
2. 下载 NapCat.Shell.Windows.OneKey.zip 并解压
3. 运行 NapCatInstaller.exe，等它自动装好 QQ NT 和 NapCat
4. 完成后会得到 NapCat.xxxxx.Shell 文件夹

第 2 步  扫码登录小号
--------------------
1. 进入 NapCat.xxxxx.Shell 文件夹
2. 右键 start-napcat.cmd（没有就用 launcher.bat）→ 以管理员身份运行
3. 控制台出现二维码 → 手机 QQ 切到小号扫码
4. 登录成功后这个窗口别关（关了 NapCat 就停了）

提示：二维码会过期，过期了就重新运行 start-napcat.cmd。

第 3 步  开两个网络配置
----------------------
1. 浏览器打开 http://127.0.0.1:6099
2. 首次进入要填 token：打开同目录 config\webui.json，复制 "token" 的值
3. 进入「网络配置」，新建两条：

   ① HTTP 服务器
      端口 3000，token 留空，启用

   ② HTTP 上报（Webhook）
      地址 http://127.0.0.1:6199/onebot
      消息格式 array，启用

4. 保存后按提示重启 NapCat（或重新执行第 2 步）

第 4 步  在桌宠里填 QQ 号
------------------------
右键桌宠 → 设置 → QQ 桥接：

   机器人 QQ 号：小号（第 2 步登录的那个）
   主人 QQ 号  ：你的大号
   NapCat 地址 ：http://127.0.0.1:3000（默认，不用改）

点「测试 NapCat」，显示昵称就说明通了 → 保存。

第 5 步  手机开聊
----------------
· 私聊：用大号加小号为好友，直接发消息
· 群聊：把小号拉进群，@它 或消息里带「大肥鱼」才会回
· 人设 / 语气 / 回复条数：设置 → QQ 桥接，或右键 → QQ 接入向导


电脑权限（可选）
--------------
设置 → QQ 桥接 → 电脑与工具权限：
  允许她使用工具（总开关）
  执行命令（默认关，开了才能跑 shell）
  读写文件（受下面的目录白名单限制）
  交给 DSH 执行
只有主人 QQ 能触发工具，关机/格式化等危险命令会被拒绝。
直接用人话就行：「看看现在 DSH 有什么任务」「查一下 D 盘剩多少空间」。

工作助手（可选）
--------------
设置 → QQ 桥接 → 工作助手，勾上「接入 DeepSeek Harness」（启动器路径可留空自动查找）。
在 QQ 里发：
  /任务              看 DSH 任务板和我的待办
  /任务 新增 内容     记一条待办
  /任务 完成 关键词   标记完成
  /dsh 目标          交给 DSH 执行，好了回传给你
  /status            看接入状态
勾上「监测任务板」后，任务完成/失败会私聊通知你。

设置里勾上「NapCat 掉线自愈」，掉线会自动尝试重启并提醒你扫码。

出问题先看这里
--------------
二维码过期          重新运行 start-napcat.cmd
QQ 一启动就退出     控制台出现 GPU process ... Goodbye 时，
                    换一个 QQ NT 版本重装，或更新显卡驱动
测试 NapCat 失败    检查 3000 端口是否被占用、token 是否两边一致
收到消息不回复      群里需要 @ 或关键词；私聊检查「私聊白名单」
回复 401            插件里的 OneBot Token 和 NapCat 的上报 token 不一致
回复很慢            DeepSeek 排队或余额不足，看设置 → API 配置的余额

安全提醒
--------
· 小号长期挂第三方协议有被限制登录的风险
· NapCat 的 6099 端口只在本机用，不要映射到公网
· 不要把 API Key、token 截图发到群里
